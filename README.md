# Genetic Algorithm Web Application

A web-based Genetic Algorithm (GA) simulator built with:

- Backend: C
- Frontend: HTML, CSS, JavaScript
- Communication: HTTP + JSON

This project demonstrates how a Genetic Algorithm evolves a population of candidate solutions to match a target binary string using Selection, Crossover, Mutation, and Elitism.

---

# Features

- Interactive web interface
- Adjustable GA parameters
- Real-time execution
- Binary chromosome optimization
- Tournament Selection
- Single-Point Crossover
- Bit-Flip Mutation
- Elitism Support
- JSON API
- Fitness Tracking
